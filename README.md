# Ublue-OS-Wallpapers

[![Copr build status](https://copr.fedorainfracloud.org/coprs/tulilirockz/ublue-os-wallpapers/package/ublue-os-wallpapers/status_image/last_build.png)](https://copr.fedorainfracloud.org/coprs/tulilirockz/ublue-os-wallpapers/package/ublue-os-wallpapers/)

Unofficial wallpapers for the [Universal Blue](https://universal-blue.org/) project.

All these wallpapers were an amazing work made by [@xynydev](https://github.com/xynydev)! I just packaged them and put them into COPR :>

## Installation

Mainly made to be installed in Fedora Silverblue and Universal Blue based systems, you can add this COPR to your system and install ublue-os-wallpapers

```shell
# Get this repo
sudo wget https://copr.fedorainfracloud.org/coprs/tulilirockz/ublue-os-wallpapers/repo/fedora-39/tulilirockz-ublue-os-wallpapers.repo -O /etc/yum.repos.d/ublue-os-wallpapers.repo

rpm-ostree install --from repo='copr:copr.fedorainfracloud.org:tulilirockz:ublue-os-wallpapers' ublue-os-wallpapers
```
